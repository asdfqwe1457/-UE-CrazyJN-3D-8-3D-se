为什么你的 UE 角色还是“假”的？皮肤、毛发与微细节进阶技巧
UE 角色做到一定程度，很多人会卡在同一个瓶颈：模型精度上去了，材质贴图也做了，渲染出来还是透着一股“假”——像蜡像、像塑料、像游戏 demo 里的展示模型。问题往往不在大结构，而在皮肤、毛发和微细节这三块最吃功夫的地方。下面拆开讲，每块说清楚“假在哪”和“怎么破”。

第一，皮肤：假的根源是均匀，真的秘密是分层。 UE 里皮肤假，最常见的原因是整张脸一个质感：亮度均匀、粗糙度均匀、没有血色变化。真实皮肤是多层结构：角质层、表皮、真皮、皮下血管，每层的散射和颜色都不同。进阶做法是给皮肤做分层控制——底色层负责整体肤色，次表面层控制透光感和血色，细节层加毛孔、细纹、轻微色斑。重点是打破均匀：额头和鼻头粗糙度略高、脸颊和眼周透光感略强、下颌和耳垂带一点血色。次表面散射不能全局拉同一个值，要按部位区分：耳朵、鼻翼、指尖透光强，脸颊中等，额头弱。皮肤的“真”来自不均匀，均匀就是塑料感的第一来源。

第二，毛孔与微纹理：不是加细节，是加尺度。 很多人以为毛孔就是贴一张噪声图，结果满脸均匀的颗粒，反而更假。真实毛孔有尺度差异：鼻翼和面颊内侧毛孔大而密，额头和颧骨外侧细而疏，下巴有走向性。做法是分区控制毛孔密度和大小，再用一张大的凹凸图打底、一张细节法线图做毛孔、一张微法线做皮肤纹理，三层叠加而不是一层硬撑。粗糙度也要跟毛孔联动：毛孔区域粗糙度略高，平滑区域略低，高光才会碎得自然。微细节的关键不是有细节，是细节有尺度、有分布逻辑。

第三，毛发：假的不是数量，是分组和透光。 UE 里毛发假，通常三个问题：一根根均匀分布像刷子、发根发梢没有粗细变化、整体不透光像塑料丝。进阶做法是先分组：前发、侧发、后发、碎发各成组，每组有自己的走向和密度；发根粗发梢细，发梢还要有分叉和飞散。材质上要有透光：强光下发梢边缘要透出暖色或发色，不能是实心黑块。毛发的高光也要分组走，不能全头一条高光带。还有一个易忽略的点：毛发和皮肤的接触区要有阴影过渡，否则像假发套上去。毛发的高级感来自分组、透光和边缘飞散，不是来自发丝数量。

第四，眼睛：假的集中爆发区。 眼睛是角色“活不活”的关键。常见假法：眼球是光滑球体、虹膜一张贴图糊到底、高光一个白点不动。真实眼睛要做四层：角膜层有反射和湿润高光、虹膜层有放射状纹理和深浅变化、瞳孔层有深度和边缘过渡、巩膜层带血丝和冷暖变化。高光不能一个点，要有主高光加辅助高光，且随视角变化。眼睑和睫毛的阴影要投在眼球上，眼睛才嵌在脸里而不是贴上去。眼睛对了，角色立刻从“模型”变成“人”。

第五，微细节的整体逻辑：统一尺度，控制密度。 微细节最容易翻车的地方是尺度混乱：毛孔巨大、毛发过粗、布料纹理比脸还抢戏。做法是先定一个基准尺度，所有微细节按这个尺度等比配置，再按视觉中心分配密度：脸和手最密，躯干次之，四肢和配景概括。另一个关键是微细节要服务材质语言：皮肤微细节是柔和的，金属是硬边的，布料是方向性的，不能所有材质用同一套噪声。微细节不是越多越好，是尺度统一、密度有主次、语言跟材质一致。

最后说练习方法：找一个你觉得“真”的 UE 角色作品，逐项拆它的皮肤分层、毛孔分布、毛发分组、眼睛结构、微细节密度，然后用自己的角色对照改一遍，每改一项渲染一次对比。做上五轮，你会发现角色从“假”到“真”的差距，从来不在模型面数，而在这些最吃观察力的地方。皮肤要分层、毛孔要尺度、毛发要分组透光、眼睛要结构、微细节要统一——这五条守住了，你的 UE 角色才真正开始有“人味”。
